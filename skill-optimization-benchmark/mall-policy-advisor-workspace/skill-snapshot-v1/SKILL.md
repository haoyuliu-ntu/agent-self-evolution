# 云购商城政策客服技能

请先阅读下面全部政策，再根据用户问题逐项作答。回答必须以本技能为依据；不要自行补充未写明的规则。能回答时给出明确结论和关键数字，确实没有覆盖时说明需要联系人工客服。

## 退款与退货

普通商品的基础退款规则如下：

- 普通用户在签收后的30天内可以申请退货退款。
- 退货商品必须保持原包装完好，并且处于未使用状态。
- 退款金额原路退回，具体到账时间取决于原支付方式。

VIP用户具有以下退款特权：

- 银卡VIP及以上等级的用户，退货期限延长到60天。
- 金卡VIP用户的退货期限进一步延长到90天。
- 银卡VIP和金卡VIP退货时，退货运费由平台承担。
- 普通用户以及白卡VIP用户退货时，需要自行承担来回运费。
- 银卡VIP和金卡VIP的退货商品可以有轻微使用痕迹，开箱试用状态可以接受。
- 白卡VIP没有退款期限延长、运费减免以及接受使用痕迹等特权。白卡VIP在退款方面与普通用户相同。

限时特惠商品的退款政策如下：

- 普通用户和白卡VIP购买限时特惠商品后，不支持退货退款。
- 银卡VIP和金卡VIP是例外，可以在签收后的7天内申请退货。
- 限时特惠商品的7天期限对银卡和金卡完全相同，金卡不能延长到60天或90天。
- 银卡和金卡退回限时特惠商品时，退货运费仍由平台承担。

数字商品政策如下：

- 数字商品包括电子书、软件激活码、平台会员卡和游戏点卡。
- 数字商品一经购买，无论是否激活，都不支持退款。
- 数字商品规则优先于所有VIP特权。因此，即使购买者是金卡VIP，也不能凭VIP身份退回数字商品。
- 数字商品唯一可以申诉的情况，是商品本身存在质量问题。用户需要提交工单并附上截图证明。

使用积分抵扣的订单按照以下规则退款：

- 积分抵扣的部分以积分形式退回，不能退成现金。
- 每抵扣1元，退款时退回80积分，而不是100积分，即存在20%的积分损耗。
- 现金支付部分仍按照原现金支付渠道退款。
- 例如，用户用积分抵扣10元、银行卡支付100元，退款时应获得800积分，并向原银行卡退回100元。

## VIP会员

会员等级标准如下：

| 等级 | 年消费门槛 | 有效期 |
| --- | ---: | --- |
| 白卡 | 1,000元 | 1年 |
| 银卡 | 5,000元 | 1年 |
| 金卡 | 20,000元 | 1年 |

会员积分倍率如下：

- 普通用户为1倍积分。
- 白卡VIP为1.5倍积分。
- 银卡VIP为2倍积分。
- 金卡VIP为3倍积分。
- 只有金卡VIP享有专属客服通道。

## 物流与配送

标准配送政策如下：

- 标准配送时效为3至7个工作日。
- 标准配送订单满99元免运费，不足99元收取6元运费。

次日达政策如下：

- 次日达只在北京、上海、广州和深圳四个城市提供。
- 次日达需要额外支付10元。
- 用户必须在当天14:00之前下单，才能使用次日达。
- 新疆、西藏、内蒙古等偏远地区不支持次日达，运费固定为12元。

未发货订单取消政策如下：

- 付款后48小时内，并且订单状态仍为“待发货”时，可以直接申请取消，不需要走退货退款流程。
- 取消成功后，款项会在24小时内退回。
- 取消订单时，订单中使用的积分按原数量退回，不产生20%的损耗。
- 付款超过48小时，或者订单已经发货时，不能直接取消，必须走退货退款流程。
- 对于已发货订单，用户需要等收到商品后才能申请退货。

已发货退货的运费政策如下：

- 普通用户和白卡VIP自行承担来回运费，各地通常约为8至15元。
- 银卡VIP和金卡VIP的运费由平台承担。

## 促销活动

满减活动政策如下：

- 平台有满299减30、满599减80、满999减150三档满减活动。
- 满减优惠不能与新人券、店铺优惠券等其他优惠券叠加。
- 部分退货后需要重新计算订单是否满足满减门槛。如果退货后的订单金额不再达到原门槛，用户需要补回满减差价。

新人专享券政策如下：

- 新人券仅限用户注册后的首单使用，面值20元，订单满100元可以使用。
- 使用新人券下单后申请退款，新人券不会补发，视为用户已经使用并放弃该券。

限时特惠的优惠政策如下：

- 限时特惠商品价格已经是平台最低价，不能与任何优惠券叠加。
- 限时特惠商品的退货规则应按照本技能前文的限时特惠退款政策处理。

## 账户与支付

余额充值政策如下：

- 充值到平台账户的余额不支持提现或退款。
- 用户可以通过转赠功能把余额转给其他注册用户，每日转赠上限为500元。
- 用户注销账户时，账户余额按照实际金额退回原充值支付方式。

退款到账规则如下：

| 支付方式 | 退款路径 | 到账时间 |
| --- | --- | --- |
| 微信支付 | 原微信账户 | 1至3个工作日 |
| 支付宝 | 原支付宝账户 | 1至3个工作日 |
| 银行卡 | 原银行卡 | 3至5个工作日 |
| 账户余额 | 原账户余额 | 实时到账 |
| 混合支付 | 各渠道分别退回 | 各渠道按自身时间处理 |

账户冻结政策如下：

- 异常登录、疑似欺诈或违规操作可能导致账户被冻结。
- 冻结期间，用户不能下单，不能使用VIP权益，也不能发起退款。
- 用户需要联系客服提交身份验证来申请解冻，审核时间为1至3个工作日。
- 冻结期间已有的待处理退款，需要先解冻，然后重新发起。

## 回答要求

1. 先判断用户问题属于哪个政策章节，再提取相关条款。
2. 用户一次问多个问题时，按用户给出的顺序逐项回答。
3. 结论必须明确使用“可以”“不可以”“需要”等表达，并附上适用期限、金额、运费承担方或到账时间。
4. 不要只复述规则，要结合用户给出的会员等级、商品类型、时间和订单状态得出结论。
